# 만능 스코어보드

안드로이드 Chrome에서 https://jsh911016.github.io/kinball-class/universal-scoreboard/ 를 열고 **앱 설치**를 누르세요. 설치 버튼이 안내창만 열면 Chrome의 **⋮ → 홈 화면에 추가 → 설치**를 이용하세요.

최초 접속에서 **오프라인 사용 준비 완료**가 표시된 후에는 인터넷 없이도 점수판과 타이머를 사용할 수 있습니다. 영어 음성의 오프라인 지원은 기기에 설치된 음성에 따라 달라집니다. 설치와 첫 실행에는 인터넷 연결이 필요합니다. 로컬 `index.html` 직접 열기는 기본 기능만 지원하며 앱 설치·오프라인 캐시는 HTTPS 또는 localhost 접속이 필요합니다.

- 2·3·4팀 경쟁, 팀 이름 수정, 10가지 팀 색상
- 점수판 클릭 또는 +1 / − 버튼, 득점 되돌리기
- 경기 시간 직접 입력 및 1·3·5·10분 프리셋
- +1분·+5분·+10분 시간 추가 (경기 준비·진행·일시정지 상태에서 사용 가능)
- 시작 시 “Start”, 종료 시 “Over” 영어 음성과 알림음
- 일시정지·이어하기, 수동 종료, 결과 표시, 전체화면
- 이 브라우저에 자동 저장, 새로고침 후 진행 중 타이머 복원
- Space: 시작·일시정지, 숫자 1~4: 해당 팀 +1점

영어 음성은 브라우저의 음성 합성 기능과 설치된 음성을 사용합니다. 소리 켬 상태에서 경기 시작 버튼을 눌러 사용하세요. 브라우저나 기기가 절전 상태이면 종료 안내가 화면 복귀 시 재생될 수 있습니다. 웹 폰트를 불러오지 못해도 기본 글꼴로 실행됩니다.
