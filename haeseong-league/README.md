# 해성중 스포츠클럽 연수 리그

`index.html`을 브라우저로 열면 바로 사용합니다. 별도 설치 없이 사용할 수 있고 인터넷이 없어도 기본 글꼴로 동작합니다.

- 빅발리볼 A·B·C·D조 풀리그 6경기 / 신발던지기 조별 기록전
- 점수판 + 전체 화면, 직접 점수 입력, 되돌리기, 결과 확정 및 수정
- 승점 설정, 종목별 순위, 두 종목 승점 합계
- 기기 자동 저장, JSON 백업·복원, CSV 내보내기, 인쇄

기본 승점: 승 3 / 무 1 / 패 0. 빅발리볼은 11점 선취, 10:10부터 2점 차 승리, 13점 상한입니다. 12:12에서는 다음 1점으로 승리합니다. 승리 팀을 자동 표시하고 추가 득점을 차단하며, 결과 확정 버튼으로 승점에 반영합니다. 신발던지기는 조별 합산 포인트를 입력하며 포인트(점)가 높은 순으로 순위를 정합니다. 기본 순위 승점은 9·6·3·0점이며 변경 가능합니다. 같은 기록은 공동 순위, 미입력은 순위에서 제외하고 4개 조 기록 확정 후 종합에 반영합니다. 이전 리그 기록은 백업에 보존합니다.
종목 순위는 승점·득실차·다득점 순, 모두 같으면 공동 순위입니다. 종합 순위는 승점 합계만 비교하고 같으면 공동 순위입니다.
기록은 현재 브라우저에 저장되며 여러 기기 사이에 자동 동기화되지 않습니다. 브라우저 기록 삭제 전 JSON 백업을 보관하세요.
