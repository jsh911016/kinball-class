# 킨볼 클래스

킨볼 수업 운영을 위한 교사용 웹 앱입니다.

## 데이터 보호

- GitHub Pages에는 `index.html`, `app.js`, `styles.css`, `assets`만 배포됩니다.
- 학생 명단, 점수, 출석 및 수업 기록은 GitHub 저장소에 포함되지 않습니다.
- 수업 데이터는 브라우저 기기 저장 또는 앱의 온라인 저장 기능을 사용합니다.
- 새 기기에서는 교사 잠금 PIN을 다시 설정해야 합니다.

## 권장 사용 순서

1. 교사 잠금 PIN 설정
2. 교사 ID와 PIN으로 온라인 저장 연결
3. 새 수업 시작
4. 수업 종료 후 온라인 저장 상태 확인
5. 정기적으로 JSON 백업 다운로드
